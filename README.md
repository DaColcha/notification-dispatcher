## Notification Dispatcher

Es un mini proyecto para practicar la construcción de arquitecturas orientadas a eventos (Event-Driven Architecture) integrando Spring Boot, Apache Kafka y React.

El sistema desacopla la recepción de notificaciones de su procesamiento y entrega final, permitiendo enviar mensajes a diferentes canales (Email, Discord, SMS) de manera asíncrona, tolerante a fallos y con monitoreo en tiempo real.
